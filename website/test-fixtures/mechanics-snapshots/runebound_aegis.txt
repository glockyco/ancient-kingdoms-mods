Mechanics When used by a mercenary, rank = floor(regular level ÷ 5) + floor(veteran level ÷ 10), capped at max rank. Buff Scaling Attribute contribution = WIS (mercenary's own attribute) Defense skill value at rank + attribute contribution × 0.15 Magic Resist skill value at rank + attribute contribution × 0.15 Poison Resist skill value at rank + attribute contribution × 0.15 Fire Resist skill value at rank + attribute contribution × 0.15 Cold Resist skill value at rank + attribute contribution × 0.15 Disease Resist skill value at rank + attribute contribution × 0.15 Spell haste shortens the cast by its percentage, so 20% spell haste turns the 0.1s cast into 0.08s.
