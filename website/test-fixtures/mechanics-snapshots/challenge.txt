Mechanics Mercenary Skill Rank A mercenary uses this skill at a rank set by your level and total veteran points. See Mercenary Skill Ranks. The character window shows them as the VT number beside your level, as in "Level 50 (VT 20)". Use 0 if no VT number appears.
