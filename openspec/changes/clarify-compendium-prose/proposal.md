## Why

Compendium prose sometimes describes internal recomputation instead of the player's outcome, omits the quantity or condition a number represents, and gives one concept different names across pages. The audit also exposed incorrect durations, examples, acquisition states and mechanic descriptions that require behavioral fixes rather than cosmetic edits.

## What Changes

- Review every audit candidate, merge repeated causes and reject suggestions that remove useful conditions or introduce unsupported facts.
- Correct misleading maximum-pool labels, duration precision, calculator ranks, metadata requirements, acquisition states, reputation signs, quest inventory rules, immunity exceptions, chest chances and summon conditions.
- Remove implementation narration, clarify compact skill summaries, and keep the in-game BetterBestiary formatter in parity.
- Use player-facing names consistently across reference pages, filters, search and the map. Replace internal identifiers with meaningful descriptions.
- Clarify controls, labels, repeated identities and source lists. Remove duplicated information without redesigning unrelated pages.
- Improve generated descriptions and page context using verified data. Preserve exact game names and necessary qualifications.

## Capabilities

### New Capabilities

- `reader-facing-copy`: Player-oriented wording, explicit quantities and conditions, consistent terminology, meaningful entity identity and nonredundant presentation across compendium surfaces.

### Modified Capabilities

- `skill-mechanics-card`: Replace literal prose snapshots with behavior-focused regression and rendered-interface verification.

## Impact

Website routes, shared components, summary and calculation producers, search documents, metadata, pipeline-generated text and exporter-authored profession descriptions. The BetterBestiary summary port changes with its website producer. Existing planning changes for detail titles and acquisition retain their unimplemented scope.
